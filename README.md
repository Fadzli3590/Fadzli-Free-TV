Tonton melalui pemain rasmi Unifi TV: [TV3](https://unifitv.com.my/player/channel/tv3/live/2026-11-02T02:00:00.000Z/2026-11-02T03:00:00.000Z).

Pautan pemain Unifi TV memerlukan sesi log masuk yang sah. Ia bukan pautan M3U dan tidak boleh digunakan terus dalam aplikasi IPTV.

## Cara guna
Masukkan URL TV dan URL EPG dalam aplikasi IPTV yang menyokong M3U/XMLTV. Sesetengah aplikasi akan membaca EPG terus daripada playlist.
